# Study Planning Platform
Веб-платформа для совместного планирования дополнительной учебной работы студентов и преподавателей.
Проект был разработан в рамках дипломной работы. Основная цель приложения — упростить выбор времени для дополнительных занятий, организовать взаимодействие студентов и преподавателей и объединить расписание, опросы, задачи и уведомления в одном интерфейсе.

## Demo
Демо-версия представляет frontend-часть проекта и работает на тестовых данных без подключения к серверу и базе данных.
Для просмотра доступны интерфейсы трёх ролей:
- Student
- Teacher
- Administrator
В demo-режиме можно переключаться между ролями и просматривать основные пользовательские сценарии приложения.

## Возможности
### Student
- просмотр расписания;
- участие в опросах по выбору времени дополнительного занятия;
- выбор нескольких подходящих вариантов времени;
- просмотр созданных событий;
- работа с личными задачами;
- просмотр уведомлений.

### Teacher
- создание опросов для выбора времени занятия;
- добавление нескольких вариантов времени;
- просмотр результатов голосования студентов;
- выбор итогового времени занятия;
- просмотр и управление своими событиями;
- получение уведомлений об изменениях.

### Administrator
- управление пользователями;
- создание учебных групп;
- добавление студентов в группы;
- просмотр основных данных системы.

## Рекомендация времени занятия
В проекте реализована логика рекомендации наиболее подходящего времени для дополнительного занятия.
При выборе учитываются:
- количество голосов студентов;
- доля голосов за определённый вариант;
- минимальное необходимое количество голосов;
- доступность преподавателя;
- отсутствие конфликтов с расписанием группы;
- удобство выбранного времени.
После анализа доступных вариантов преподаватель может выбрать итоговое время занятия.

## Архитектура
Frontend приложения построен на React.
Интерфейс разделён на компоненты и страницы для разных пользовательских ролей. В полной версии приложения frontend взаимодействует с серверной частью через REST API.
Backend реализован на Node.js и Express, а для взаимодействия с MySQL используется Prisma ORM.
Для demo-версии серверные запросы заменены тестовыми данными, поэтому приложение может работать независимо от backend.
